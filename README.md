# 📝 モバイルタスク管理アプリ

React + Vite で作ったスマホ対応のタスク管理アプリです。

## 機能

- タスクの追加・完了・削除
- カテゴリ分類（仕事 / 個人 / 買い物 / 健康）
- 優先度設定（高 / 中 / 低）
- ステータスフィルター（すべて / 未完了 / 完了）
- 左スワイプで削除
- 進捗プログレスバー
- localStorage でデータ永続化
- PWA 対応（ホーム画面に追加可能）

## 起動方法

```bash
npm install
npm run dev
```

## ビルド

```bash
npm run build
```
